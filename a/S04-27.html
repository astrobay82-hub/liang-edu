情緒爆炸結束後，家長該怎麼收尾？

情緒爆炸結束後，才是真正教孩子的開始

神經與大腦適用 2–12歲約 3 分鐘
衛教圖卡

醫師叮嚀情緒爆炸後，不是急著追究誰對誰錯，而是帶孩子走完「冷靜、理解、修復、再練一次」的過程。

重點速讀詳細衛教中醫觀點何時就醫衛教圖卡參考資料

3 分鐘重點速讀

孩子大哭、大叫、踢東西時，家長通常最辛苦的是「怎麼讓他停下來」。

但很多家庭忽略了一件事：孩子安靜之後，怎麼收尾，其實同樣重要。

情緒爆炸時，孩子的大腦處於高度喚醒狀態，當下要他聽大道理、分析對錯，效果通常有限。即使哭聲停止，身體與情緒也可能還沒有完全平穩。

因此第一步不是立刻質問，而是先讓孩子重新回到安全與穩定。

可以喝水、洗臉、抱一下、坐在旁邊，或者只是安靜陪伴幾分鐘。

等孩子真正能對話後，再進入第二步：幫他理解剛才發生了什麼。

例如：

「剛才媽媽說不能再看平板，你真的很生氣。」

「你本來很想贏，輸掉之後覺得很難受。」

這不是替孩子找藉口，而是在幫他建立「情緒語言」。

接下來才是第三步：修復行為。

有情緒沒有錯，但打人、罵人、摔東西仍然需要處理。可以請孩子向對方道歉、把丟掉的東西撿回來，或討論下一次可以怎麼做。

最重要的是，不要把情緒和行為混在一起。

可以告訴孩子：

「你可以很生氣，但是不能打人。」

如此孩子才會慢慢理解：

情緒可以被接受，行為仍然有界線。

一次爆炸不一定能教會孩子，但每一次穩定、回顧與修復，都在幫孩子的大腦累積下一次做得更好的經驗。

深入詳細衛教

情緒爆炸結束後，家長該怎麼收尾？

孩子情緒爆炸時，許多家長會把所有力氣都花在「怎麼讓他停下來」。

但真正影響孩子下一次能不能進步的，常常是爆炸結束之後發生了什麼。

建議家長掌握以下四個步驟。

第一階段｜先確認孩子真的平靜下來

孩子停止哭泣，不代表神經系統已經完全恢復。

如果孩子仍然喘得很快、拳頭緊握、不願意看人、回答很衝，表示他可能還在高度喚醒狀態。

這時先不要急著檢討。

可以：

  • 喝水
  • 洗臉
  • 抱抱
  • 坐在安靜的地方
  • 做幾次慢慢的呼吸
  • 陪伴而不追問

目標是先把身體帶回穩定。

第二階段｜重新建立連結

有些家長會故意冷落孩子，希望讓孩子知道「發脾氣是不對的」。

但情緒爆炸之後，孩子更需要確認一件事：

「即使我剛剛失控，大人仍然在這裡。」

重新連結不代表縱容。

可以說：

「剛才真的很辛苦，我們先坐一下。」

「現在好多了，我在這裡。」

孩子感受到安全後，大腦才比較能重新進入學習狀態。

第三階段｜幫孩子把事件說清楚

不要開始長篇說教，而是簡單整理：

發生什麼事 → 有什麼感受 → 做了什麼行為。

例如：

「剛才哥哥拿走你的玩具，你很生氣，所以你推了哥哥。」

或：

「媽媽說要關平板，你很失望，所以你開始大叫。」

這一步的目的是幫孩子建立：

「事件 → 情緒 → 行為」

之間的連結。

孩子未來才能慢慢學會在行為爆炸以前辨認自己的情緒。

第四階段｜一定要修復，但不要羞辱

情緒可以接受，傷害性的行為仍然需要負責。

例如：

丟東西 → 一起整理。
打人 → 確認對方是否受傷並道歉。
破壞物品 → 一起想辦法修復。

但避免：

「你怎麼那麼壞？」

「每次都是你。」

「你看看你把大家害成什麼樣子。」

我們要修正的是行為，而不是讓孩子覺得「我是壞孩子」。

最後可以討論：

「如果下一次又這麼生氣，你可以怎麼做？」

年紀較小的孩子，選項不要太多。

例如：

「下次可以說『我很生氣』，還是先來找媽媽？」

一次只練習一個方法。

最重要的一個觀念

不要期待一次談話就讓孩子再也不爆炸。

情緒調節本來就是需要大量重複練習的大腦能力。

真正有效的收尾不是：

「你知道錯了沒有？」

而是讓孩子一次又一次經歷：

失控 → 被帶回穩定 → 理解自己 → 修復行為 → 學習下一個方法。

這才是情緒能力慢慢長出來的過程。

情緒爆炸之後的收尾，是中醫說的「疏泄」完成的時候：氣機平順下來，心神回歸。這時候最需要的不是檢討，而是修復：抱一抱、喝點溫水、讓身體放鬆，再用簡單的話描述剛才發生的事。臨床上我發現，收尾做得好的家庭，下一次爆炸的強度通常會降低。中醫可以幫情緒起伏大的孩子平肝安神，但關係的修復，只有大人能給。

何時應該就醫評估？

  • ：幾乎每天或一天多次嚴重爆炸
  • 每次持續很久，極難恢復
  • 經常打人、咬人、踢人或破壞物品
  • 出現傷害自己或他人的行為
  • 情緒問題已明顯影響家庭、學校或同儕關係
  • 在不同場合都容易嚴重失控
  • 合併明顯注意力、過動、衝動問題
  • 合併語言、社交或感覺調節困難
  • 長期睡眠不足或睡眠品質很差
  • 孩子自己也常說「我控制不了自己」

如果情緒爆炸偶爾發生，而且經過陪伴可以逐漸恢復，多半可以先從生活與親職策略調整。

若出現呼吸困難、意識不清、抽搐不止、持續高燒或精神活動力明顯變差，請直接就醫或撥打 119。

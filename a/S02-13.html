為什麼越忍住不大便，便秘越嚴重？

孩子不是不想大，有時候是「不敢大」

腸胃與泌尿適用 2–12歲約 3 分鐘
#便秘
衛教圖卡

醫師叮嚀孩子越忍，大便越硬；大便越硬，孩子就越不敢大。

重點速讀詳細衛教中醫觀點何時就醫衛教圖卡參考資料

3 分鐘重點速讀

不少家長會發現，孩子明明好像有便意，卻突然踮腳、夾緊屁股、身體扭來扭去，甚至躲到角落。

家長常以為孩子正在「用力大便」，其實這些動作反而可能是在忍便。美國兒科相關衛教資料也將踮腳、夾臀、特殊扭動姿勢列為兒童延遲排便時常見的表現。

孩子第一次開始忍便，常常有原因。

可能曾經排過一次很粗、很硬的大便，肛門疼痛甚至出血；也可能正在戒尿布，不喜歡坐馬桶；或者不願意中斷遊戲、害怕學校廁所、覺得外面的廁所很髒。

問題是，忍便本身又會讓下一次的大便更難排。

糞便留在大腸的時間越久，大腸就會持續吸收其中的水分，讓糞便愈來愈乾、愈來愈硬。下一次排便更痛，孩子因此更加害怕，形成「疼痛—忍便—硬便—再疼痛」的循環。

如果這個狀況持續很久，大量糞便可能堆積在直腸，使直腸逐漸被撐大，孩子對「我想大便」的感覺也可能變得比較不敏感。嚴重時甚至會出現糞便阻塞，較軟的糞便從硬便旁邊滲出，家長反而以為孩子在拉肚子或故意弄髒褲子。

因此治療兒童便秘，不能只要求孩子「去大便」。

更重要的是：

先讓大便變軟、不痛，再重新建立規律排便習慣。

當孩子重新累積「大便不會痛」的經驗，才比較有機會真正打破忍便循環。

深入詳細衛教

為什麼越忍住不大便，便秘會越來越嚴重？

很多兒童的慢性便秘，最初可能只是一兩次硬便。

但真正讓便秘延續好幾個月，甚至幾年的原因之一，就是忍便行為（stool withholding）。

第一階段：孩子曾經「大便很痛」

例如喝水較少、飲食改變、生病、旅行或戒尿布期間，孩子出現了一次又粗又硬的大便。

排便時肛門很痛，甚至產生小裂傷。

孩子很快就學到：

「大便＝會痛。」

於是下一次有便意時，他開始不想去廁所。

第二階段：孩子把便意「忍回去」

這時家長可能看到孩子：

  • 突然停下正在做的事情
  • 夾緊屁股
  • 兩腿交叉
  • 踮腳
  • 身體僵硬
  • 左右扭動
  • 躲到桌子或窗簾後面

看起來很像在「用力」，其實有些孩子是在用力避免大便出來。

第三階段：大便越放越乾

糞便停留在大腸裡，大腸仍會繼續吸收其中的水分。

因此：

停得越久 → 水分越少 → 大便越硬、越粗。

等到孩子真的忍不住時，要排出的可能已經不是原本那顆比較柔軟的大便，而是一顆更大、更硬的糞便。

結果當然更痛。

第四階段：「痛—忍—更硬—更痛」循環形成

這也是兒童功能性便秘很重要的機轉：

硬便
→ 排便疼痛
→ 害怕大便
→ 忍便
→ 糞便停留更久
→ 更乾、更大、更硬
→ 排便更痛
→ 更加忍便

所以單純跟孩子說：

「你有大便就趕快去啊！」

往往沒有辦法解決問題。

因為對孩子來說，他正在避免一件「曾經讓自己很痛」的事情。

第五階段：忍太久，連便意都可能變弱

如果直腸長期堆積大量糞便，直腸會持續被撐開。

久而久之，孩子可能不像以前那麼容易察覺便意。

家長就會發現：

「以前還會說想大便，現在好像完全都沒感覺。」

嚴重便秘時，甚至可能出現較軟或液狀糞便從硬便旁邊滲出來，造成內褲反覆沾便。這不是孩子故意，也不代表便秘已經改善，有時反而提示直腸裡累積了不少糞便。

要怎麼打破這個循環？

重點不是「逼孩子大」，而是重新建立三件事：
① 先讓便便軟下來
如果每次排便還是很痛，孩子很難停止忍便。

② 建立固定排便時間

可以利用吃完飯後腸胃反射較活躍的時段，安排孩子坐馬桶。美國 NIDDK 也建議已完成如廁訓練的孩子，可在餐後固定如廁建立習慣。

③ 不責備、不催促

把目標從「今天一定要大出來」，改成「願意坐、願意感受便意」。

如果已經有明顯糞便堆積，有些孩子需要先由醫師評估是否進行清便及後續維持治療；單靠水分和蔬菜，不一定足以打破已經形成的忍便循環。

越忍越便秘，中醫可以這樣理解：大便在腸道停留越久，水分被吸得越乾，就越難排；每次排便都痛，孩子就更想忍，氣機越鬱滯。打破循環的第一步，是讓大便變軟、讓排便不痛，再重建「有便意就去」的習慣。中醫調理以潤腸通便、行氣導滯為主，配合固定在餐後10–15分鐘坐馬桶、腳下墊小凳子。家長的態度很重要：鼓勵、不催促，孩子才願意放鬆。

何時應該就醫評估？

  • ：反覆排便疼痛或因害怕而明顯忍便
  • 大便非常粗硬
  • 肛門反覆裂傷、出血
  • 經常腹痛或明顯腹脹
  • 食慾明顯下降
  • 反覆內褲沾便
  • 長時間沒有便意
  • 疑似有大量糞便堆積
  • 居家飲食、排便訓練後仍持續便秘

如果孩子便秘已經持續超過約2週、反覆發作，或居家調整仍沒有改善，建議由醫師進一步評估。

若出現呼吸困難、意識不清、抽搐不止、持續高燒或精神活動力明顯變差，請直接就醫或撥打 119。
